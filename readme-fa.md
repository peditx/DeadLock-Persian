# مود فارسی ددلاک — Deadlock Persian

یک مود فارسی‌سازی تمیز و دقیق برای بازی Deadlock شرکت والو.

🌐 **سایت:** [games.peditx.ir](https://games.peditx.ir)

---

## ✨ فیچرها

- **ابیلیتی‌های هیروها** — توضیحات کامل فارسی برای همهٔ هیروها، شامل Hero Labs
- **لور هیروها** — تمام ۴۷ لور هیرو ترجمه شده
- **توضیحات آیتم‌ها و شاپ** — به زبان طبیعیِ گیمرها
- **منوی Settings** — کل بخش تنظیمات (ویدیو، صدا، کی‌بایند، دوربین، دسترس‌پذیری، شاپ، چت و...) به فارسی
- **لوگوی اختصاصی** — صفحهٔ لودینگ با لوگوی شخصی
- **دیالوگ‌های هیروها** — ویس‌لاین‌های داخل بازی به صورت متن
- **کارت‌های آپگرید** — کارت‌های استت Tier 1 / Tier 2 / Tier 3 عمداً انگلیسی میمونن تا استت‌ها و نامبرها شفاف و خوانا باشن
- **RTL درست** — رندر راست‌به‌چپ صحیح: بدون عدد برعکس، پرانتز خراب، یا به هم ریختگی UI
- **صفر اثر روی گیم‌پلی** — مودِ خالص متنی: بدون اسکریپت، بدون هزینهٔ پرفورمنس

---

## 📦 روش نصب

1. فایل `pak82_dir.vpk` رو دانلود کن.
2. فایل `.vpk` رو توی پوشهٔ مود بازی کپی کن:

```
...\Steam\steamapps\common\Deadlock\game\citadel\addons\
```

(اگه پوشهٔ `addons` داخل `citadel` وجود نداره، خودت بسازش.)

3. توی فایل `gameinfo.gi` (located `...\Steam\steamapps\common\Deadlock\game\citadel`)، مطمئن شو مسیر addons اینطوری هست:

```
            Game_Language "citadel_*LANGUAGE*"
            Game          "citadel/addons"

            Mod   "citadel"
            Write "citadel"
            Game  "citadel"
            Mod   "core"
            Write "core"
            Game  "core"
```

4. بازی رو اجرا کن و لذت ببر!

## 🗑️ حذف مود

فایل `pak82_dir.vpk` رو از پوشهٔ `addons\` پاک کن.

## 🇬🇧 چیزهایی که عمداً انگلیسی میمونن

Soul، Deny، کارت‌های استتِ تایرها، اسم هیروها / ابیلیتی‌ها / آیتم‌ها، و اصطلاحات فنی مثل **FPS**، **VSync**، **DLSS** — کلماتی که هر گیمر ددلاک استفاده میکنه.

## 🚧 در حال کار

بقیهٔ منوهای بازی، تگ‌های هیرو، و زیرنویس‌های داخل بازی (VO).
